Лист персонажа: лисичка.md
Картинки: папка images/ (можно все файлы россыпью)
Память: папка memory/ (чат и факты только этого персонажа)

Как добавить кадр и позу
1. Положи PNG в images/. Имя файла без .png = имя кадра.
   Пример: hands_close.png → в чате можно будет [ANIM:hands_close]
2. В poses.json добавь строку:
   {"keys": ["что в руках", "покажи руки"], "anim": "hands_close"}
3. Перезапусти ассистента.

Готовые кадры (111 штук) уже размечены по смыслу, отдельной фотографии «хвост крупно» нет:
- хвост / ушки → sly
- руки / что держишь → pointing
- тело ближе / грудь → lingerie
- спина / попа → teasing
- лицо ближе → blush
- танец → dance
- разденься → undress
«покажи все позы» или «следующий кадр» — пролистать все файлы из images/.
Настроение живое: кадр сам меняется каждые ~20 сек, если не просил конкретную позу.
